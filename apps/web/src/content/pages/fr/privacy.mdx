## Chat IA (« Yue AI »)

- Les conversations avec l'assistant IA de ce site sont stockées **uniquement dans le stockage local de votre navigateur**, jamais sur le serveur.
- Le serveur ne conserve pas vos messages ni les réponses de l'assistant. Chaque requête est traitée et la réponse vous est renvoyée en streaming ; le texte de la conversation lui-même n'est écrit dans aucune base de données.
- Le serveur enregistre des métriques légères, sans contenu, à des fins de fiabilité et de suivi des coûts : temps de réponse, une estimation du nombre de tokens, quel fournisseur/modèle d'IA a traité la requête, le statut de la requête et l'endpoint. Ces enregistrements ne contiennent jamais le texte de votre message.
- Vos données **ne sont pas utilisées pour entraîner un quelconque modèle d'IA**. Rien de ce que vous tapez ici n'est envoyé pour l'entraînement de modèles, le fine-tuning ou des jeux de données d'évaluation.
- Si vous utilisez les boutons j'aime/je n'aime pas sur une réponse du chat, nous stockons l'évaluation (j'aime ou je n'aime pas) et un commentaire facultatif que vous rédigez, liés à ce message spécifique, avec la page, le fournisseur, le modèle et la langue. Ce retour n'inclut pas le reste de la conversation.

## Ce que nous collectons

Pour que le site continue de fonctionner, reste sécurisé et sans spam, certaines requêtes sont journalisées :

- **Adresse IP, user agent et horodatages** pour la limitation de débit (par exemple formulaire de contact, newsletter, chat IA) et pour les journaux d'erreur/sécurité en cas de problème.
- **Événements analytiques de base** (vues de page et interactions similaires), incluant l'adresse IP et le user agent, pour comprendre comment le site est utilisé.
- Les **soumissions du formulaire de contact** sont vérifiées avec Cloudflare Turnstile avant traitement, afin de filtrer le spam automatisé.
- Si vous créez un compte (pour commenter, utiliser le livre d'or, etc.), des données de compte standard (e-mail, jetons de session, tentatives de connexion) sont stockées pour faire fonctionner l'authentification.

## Ce que nous ne faisons pas

- Nous ne vendons pas vos données.
- Nous n'utilisons pas vos messages du chat IA à des fins publicitaires ou de profilage.
- Nous n'entraînons ni ne faisons de fine-tuning d'un modèle d'IA avec les données collectées sur ce site.
