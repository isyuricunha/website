Esta página explica, en un lenguaje simple, qué hace y qué no hace este sitio con tus datos. No sustituye un asesoramiento legal, pero es una descripción honesta del código que realmente ejecuta este sitio.

---

## Chat de IA ("Yue AI")

- Las conversaciones con el asistente de IA de este sitio se almacenan **únicamente en el almacenamiento local de tu navegador**, nunca en el servidor.
- El servidor no guarda tus mensajes ni las respuestas del asistente. Cada solicitud se procesa y la respuesta se transmite de vuelta a ti; el texto de la conversación en sí no se escribe en ninguna base de datos.
- El servidor registra métricas ligeras y sin contenido, para fiabilidad y monitoreo de costos: tiempo de respuesta, una estimación de tokens, qué proveedor/modelo de IA atendió la solicitud, el estado de la solicitud y el endpoint. Estos registros nunca contienen el texto de tu mensaje.
- Tus datos **no se usan para entrenar ningún modelo de IA**. Nada de lo que escribes aquí se envía para entrenamiento de modelos, fine-tuning o conjuntos de datos de evaluación.
- Si usas los botones de me gusta/no me gusta en una respuesta del chat, almacenamos la valoración (me gusta o no me gusta) y un comentario opcional que escribas, vinculados a ese mensaje específico, junto con la página, proveedor, modelo e idioma. Este feedback no incluye el resto de la conversación.

## Qué recopilamos

Para mantener el sitio funcionando, seguro y libre de spam, algunas solicitudes se registran:

- **Dirección IP, user agent y marcas de tiempo** para limitación de tasa (por ejemplo, formulario de contacto, newsletter, chat de IA) y para logs de error/seguridad cuando algo falla.
- **Eventos básicos de analítica** (vistas de página e interacciones similares), incluyendo dirección IP y user agent, para entender cómo se usa el sitio.
- Los **envíos del formulario de contacto** se verifican con Cloudflare Turnstile antes de procesarse, para filtrar spam automatizado.
- Si creas una cuenta (para comentar, usar el guestbook, etc.), se almacenan datos estándar de cuenta (correo electrónico, tokens de sesión, intentos de inicio de sesión) para que funcione la autenticación.

## Qué no hacemos

- No vendemos tus datos.
- No usamos tus mensajes del chat de IA para publicidad ni perfilamiento.
- No entrenamos ni hacemos fine-tuning de ningún modelo de IA con datos recopilados en este sitio.
