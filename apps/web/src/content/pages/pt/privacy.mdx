Esta página explica, em linguagem simples, o que este site faz e não faz com os seus dados. Não substitui um parecer jurídico, mas é uma descrição honesta do código que roda de fato neste site.

---

## Chat de IA ("Yue AI")

- As conversas com o assistente de IA deste site são armazenadas **apenas no armazenamento local do seu navegador**, nunca no servidor.
- O servidor não guarda suas mensagens nem as respostas do assistente. Cada requisição é processada e a resposta é transmitida de volta a você; o texto da conversa em si não é gravado em nenhum banco de dados.
- O servidor registra métricas leves e sem conteúdo, para confiabilidade e monitoramento de custo: tempo de resposta, uma estimativa de tokens, qual provedor/modelo de IA atendeu a requisição, o status da requisição e o endpoint. Esses registros nunca contêm o texto da sua mensagem.
- Seus dados **não são usados para treinar nenhum modelo de IA**. Nada que você digita aqui é enviado para treinamento de modelo, fine-tuning ou datasets de avaliação.
- Se você usar os botões de curtir/não curtir numa resposta do chat, armazenamos a avaliação (curtir ou não curtir) e um comentário opcional que você escrever, vinculados àquela mensagem específica, junto com a página, provedor, modelo e idioma. Esse feedback não inclui o restante da conversa.

## O que nós coletamos

Para manter o site funcionando, seguro e livre de spam, algumas requisições são registradas:

- **Endereço IP, user agent e horários** para limitação de taxa (ex: formulário de contato, newsletter, chat de IA) e para logs de erro/segurança quando algo dá errado.
- **Eventos básicos de analytics** (visualizações de página e interações semelhantes), incluindo endereço IP e user agent, para entender como o site é usado.
- **Envios do formulário de contato** são verificados com Cloudflare Turnstile antes de serem processados, para filtrar spam automatizado.
- Se você criar uma conta (para comentar, usar o guestbook, etc.), dados padrão de conta (e-mail, tokens de sessão, tentativas de login) são armazenados para o funcionamento da autenticação.

## O que nós não fazemos

- Não vendemos seus dados.
- Não usamos suas mensagens do chat de IA para publicidade ou perfilamento.
- Não treinamos nem fazemos fine-tuning de nenhum modelo de IA com dados coletados neste site.
