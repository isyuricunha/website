## About YuArc

A minimalist analog watch face for Garmin smartwatches, built with the Connect IQ SDK in Monkey C. Designed around a small set of choices: legibility first, only the data fields you actually glance at, no flashy animations draining the battery.

### Design

- Clean analog dial with subtle accent color
- Minimal complications (time, date, battery)
- Battery-friendly rendering loop
- Works with most modern Garmin watches that support Connect IQ

If you like a watch that tells the time without screaming, this is the one.
