## About Ella

Ella is an autonomous AI agent designed to live inside your GitHub repositories and help you run them like a maintainer. She can triage issues, review PRs, follow up on CI, and coordinate work with humans and other agents — all from within the same repository you already work in.

### Key Features

- Lives natively inside GitHub — no external orchestrator required
- Long-term memory of the repo's conventions and past decisions
- Follows the branching and PR workflow the repo already uses
- Talks to the wider ecosystem (CI, release automation, kanban boards)
- Acts like a real collaborator, not a code generator

### Where it runs

Ella is being used in production on this very repository ([isyuricunha/ella](https://github.com/isyuricunha/ella)) and acts as the maintainer agent of this site.
