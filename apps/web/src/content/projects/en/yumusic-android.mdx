## About YuMusic Android

A modern Android music streaming client for self-hosted libraries. Built with Jetpack Compose and Material 3, designed with clean architecture in mind (MVVM + Hilt + Room + Coil) so the codebase stays testable and modular.

### Stack

- **Jetpack Compose** — declarative UI
- **Hilt** — dependency injection
- **Room** — local caching and playlists
- **Coil** — fast image loading
- **Material 3** — Material You dynamic colors

The app talks to a Subsonic API as well, so a single library covers the watch (Garmin), the desktop (Electron), and Android.
