## About MCP DDG Research

A minimal Model Context Protocol (MCP) server that brings DuckDuckGo search into your AI agents, with clean page fetching, HTML-to-text extraction, and a local cache so you never re-hit the same page.

### Features

- DuckDuckGo HTML search via a zero-tracking endpoint
- Optional `ddgs` library mode for richer query results
- Safe page fetching with sensible User-Agent, content-type filtering, and timeout
- Built-in result cache — same URL never fetches twice
- Markdown-ready text extraction from most HTML pages

### Why MCP

Plug it into Claude Desktop, Cursor, or any other MCP-compatible client and the AI stops hallucinating URLs. Instead of recalling outdated information, it can search fresh content on demand and cite its findings.
