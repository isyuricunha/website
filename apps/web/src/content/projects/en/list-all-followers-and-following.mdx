## About List All Followers and Following

GitHub's native UI makes it painful to browse through all your followers and people you follow — no filtering, no sorting, clunky pagination. This small project fixes that by rendering your full following/follower list as a sortable, filterable table that auto-updates on a schedule.

### Key Features

- See **all** followers and following in one long table (no "load more" clicks)
- Live filter and sort by name, company, location, blog, bio
- Auto-updated daily via a scheduled GitHub Action
- Zero backend — the data is committed to the repo as a static asset

### Why it exists

GitHub lets you follow hundreds of people but the built-in page makes it unusable past about 50. This is what my follower list should have been from the start.
