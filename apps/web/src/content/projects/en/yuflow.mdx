## About YuFlow

YuFlow is a task manager built around one axiom: **your data belongs to you**. No accounts, no cloud, no telemetry, no analytics. The app runs entirely on your device — as a Tauri 2.0 desktop app or as a web PWA — and stores everything locally in SQLite/IndexedDB.

### Privacy Manifesto

- 100% local storage, always
- Zero telemetry — no tracking, no analytics, no fingerprinting
- No cloud dependencies — works fully offline
- Full data ownership — export, backup, migrate whenever
- Auditable open-source codebase

### Features

- Kanban-style task boards with subtasks and attachments
- Recurring tasks, due dates, priorities, tags
- Dark "True Pure Black" theme with accent colors
- Native desktop (Tauri) + web (PWA) builds from the same codebase
- Full-text search across all projects

### Stack

TypeScript, Tauri 2 (Rust shell), SQLite on desktop, IndexedDB in the browser. No server-side component.
