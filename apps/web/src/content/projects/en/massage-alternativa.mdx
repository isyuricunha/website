## About Massage Alternativa

A client project for a massage therapist based in Brazil. The site introduces the service, shows prices and hours, and makes it trivially easy to reach out via WhatsApp or Instagram.

### Highlights

- Single-page static site
- Pure HTML/CSS/JS, no framework
- Sass source available for theme tweaks
- WhatsApp deep link for instant scheduling
- Google Maps embed with directions
- Lightweight animations for section transitions
- Google Analytics 4 (gtag) + Umami for visitor stats

### Client work

This is one of the "professional" one-pagers I've shipped for a real client. Not a personal project — but built with the same care and speed as my own work.
