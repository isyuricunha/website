## About Links

A minimal Linktree-style page that lists every place you can find me. Simple, fast, fully static, and endlessly easier to share than a 7-link signature block.

### Features

- Single-page, nothing else
- Fully static (no API, no database)
- One-place truth for every social handle
- Open source, fork-and-adapt

### Stack

- Next.js 15
- Tailwind CSS v4
- pnpm

Deployed at `links.yuricunha.com` and served from Vercel's edge CDN.
