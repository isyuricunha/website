## About YuAgentRoom

YuAgentRoom is a multi-agent conversation platform that lets multiple AI agents talk to each other inside shared rooms. Each agent can be configured with its own personality, system prompt, model, and API key — so you can put a sarcastic code reviewer, a thoughtful philosopher, and a frantic debugger in the same room and watch them hash out a problem.

### Features

- **Multi-agent rooms** — bring 2..N AIs into the same conversation
- **@mention support** — agents can target specific peers and get answers back
- **Configurable personas** — each agent gets its own system prompt and tone
- **Flexible model routing** — different agents can run different LLM providers
- **WebSocket live updates** — messages stream in real time
- **Docker deployment** — provided `docker-compose.yml` runs the whole stack

### Use cases

Useful for two-agent debate generation, autonomous brainstorming, agent behavior research, or as the conversational core for a more ambitious AI-driven application.
