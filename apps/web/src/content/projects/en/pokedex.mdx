## About PokéDex

A full-featured Progressive Web App for browsing all 1025+ Pokémon. Built with Next.js 15, TypeScript, and Tailwind CSS v4 — installable on any device, works offline, and feels native.

### Highlights

- **Browse and search** all Pokémon with real-time filtering
- **Detailed stats** — base stats, abilities, moves, evolution chains
- **Type effectiveness** — interactive matchup chart
- **Team builder** — build and analyze teams of up to 6
- **Quiz modes** — silhouette, stats, and type quizzes
- **Comparisons** — side-by-side Pokémon analysis
- **Shiny variants** — toggle shiny sprites
- **Favorites and collections** — track your own Pokédex completion

### Why another Pokédex?

Most are slow web apps that leak memory. This one is a lean PWA with optimistic UI, locally-cached sprites, and a TypeScript codebase built for extension.
