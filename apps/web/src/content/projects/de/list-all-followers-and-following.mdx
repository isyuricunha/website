## Über List All Followers and Following

GitHubs native Oberfläche macht es mühsam, alle deine Follower und die Personen, denen du folgst, zu durchsehen – kein Filtern, kein Sortieren, umständliche Paginierung. Dieses kleine Projekt behebt das, indem es deine komplette Following-/Follower-Liste als sortierbare, filterbare Tabelle darstellt, die sich planmäßig automatisch aktualisiert.

### Wichtigste Funktionen

- **Alle** Follower und Gefolgten in einer langen Tabelle sehen (kein „Mehr laden“-Geklicke)
- Live-Filter und Sortierung nach Name, Firma, Ort, Blog, Bio
- Tägliche automatische Aktualisierung über eine geplante GitHub Action
- Kein Backend – die Daten werden als statisches Asset ins Repo committet

### Warum es das gibt

GitHub erlaubt dir, Hunderten von Personen zu folgen, aber die eingebaute Seite ist ab etwa 50 praktisch unbenutzbar. Das hier ist, was meine Follower-Liste von Anfang an hätte sein sollen.
