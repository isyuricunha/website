## Über Links

Eine minimalistische Linktree-artige Seite, die alle Orte auflistet, an denen man mich findet. Einfach, schnell, vollständig statisch – und unendlich viel einfacher zu teilen als ein Signaturblock mit sieben Links.

### Funktionen

- Eine einzige Seite, sonst nichts
- Vollständig statisch (keine API, keine Datenbank)
- Eine zentrale Anlaufstelle für alle Social-Media-Handles
- Open Source – forken und anpassen

### Stack

- Next.js 15
- Tailwind CSS v4
- pnpm

Verfügbar unter `links.yuricunha.com`, ausgeliefert über das Edge-CDN von Vercel.
