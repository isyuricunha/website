## Sobre a Ella

A Ella é um agente de IA autônomo desenhado para viver dentro dos seus repositórios GitHub e te ajudar a gerenciá-los como um mantenedor. Ela pode triar issues, revisar PRs, acompanhar o CI e coordenar trabalho com humanos e outros agentes — tudo de dentro do mesmo repositório que você já usa.

### Principais Recursos

- Vive nativamente dentro do GitHub — sem orquestrador externo
- Memória de longo prazo das convenções e decisões passadas do repo
- Segue o fluxo de branches e PRs que o repo já usa
- Fala com o ecossistema (CI, automação de release, kanban)
- Age como um colaborador real, não um gerador de código

### Onde roda

A Ella é usada em produção neste mesmo repositório ([isyuricunha/ella](https://github.com/isyuricunha/ella)) e age como a agente mantenedora deste site.
