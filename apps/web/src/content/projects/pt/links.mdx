## Sobre o Links

Uma página estilo Linktree minimal que lista todo lugar que você me encontra. Simples, rápida, totalmente estática, e infinitamente mais fácil de compartilhar que um bloco de assinatura com 7 links.

### Features

- Página única, mais nada
- Totalmente estática (sem API, sem database)
- Uma única fonte da verdade pra cada social handle
- Código aberto, fork-e-adapt

### Stack

- Next.js 15
- Tailwind CSS v4
- pnpm

Deployada em `links.yuricunha.com` e servida via Vercel edge CDN.
