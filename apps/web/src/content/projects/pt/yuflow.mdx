## Sobre o YuFlow

O YuFlow é um gerenciador de tarefas construído em torno de um axioma: **seus dados pertencem a você**. Sem contas, sem nuvem, sem telemetria, sem analytics. O app roda inteiramente no seu dispositivo — como app desktop Tauri 2.0 ou como web PWA — e guarda tudo localmente em SQLite/IndexedDB.

### Manifesto de Privacidade

- 100% armazenamento local, sempre
- Zero telemetria — nenhum rastreamento, analytics, fingerprinting
- Zero dependências de nuvem — funciona totalmente offline
- Propriedade total dos dados — exporte, faça backup, migre quando quiser
- Código aberto auditável

### Recursos

- Quadros estilo Kanban com subtarefas e anexos
- Tarefas recorrentes, datas de vencimento, prioridades, tags
- Tema dark "True Pure Black" com cores de acento
- Builds nativas desktop (Tauri) + web (PWA) do mesmo código
- Busca full-text em todos os projetos

### Stack

TypeScript, Tauri 2 (shell Rust), SQLite no desktop, IndexedDB no browser. Nenhum componente server-side.
