## Sobre o servidor dedicado de Return to Moria

Uma stack Docker autocontida para hospedar seu próprio servidor de **Lord of the Rings: Return to Moria** — sem precisar mexer manualmente no SteamCMD.

### O que você recebe

- `Dockerfile` baseado em `ghcr.io/ptero-eggs/yolks:wine_latest`
- `entrypoint.sh` que prepara o SteamCMD, instala/atualiza o servidor e o inicia via Wine
- `docker-compose.yml` com volume persistido em `./data` para o estado do jogo sobreviver a reinicializações
- `.env.example` com todos os ajustes — nome do servidor, porta, senha, política de atualização

### Como funciona

Na primeira execução, o container baixa o SteamCMD e os arquivos do servidor dedicado em `./data`. A partir daí, ele pode se atualizar automaticamente (configurável) e inicia o servidor sob Wine. A imagem em si fica pequena; o peso fica no disco do host.

### Compatibilidade

Testado no Ubuntu Server 24.04 LTS. Deve funcionar em qualquer Linux x86_64 moderno com Docker instalado.
