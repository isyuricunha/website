## Sobre List All Followers and Following

A UI nativa do GitHub torna doloroso navegar por todos os seus seguidores e quem você segue — sem filtro, sem ordenação, paginação chata. Este projeto pequeno corrige isso renderizando sua lista completa de following/followers como uma tabela ordenável e filtrável que auto-atualiza em schedule.

### Principais Recursos

- Veja **todos** seguidores e following numa tabela única (sem clicar "load more")
- Filtro e ordenação ao vivo por nome, empresa, localização, blog, bio
- Auto-atualizado diariamente via GitHub Action agendado
- Zero backend — o dado é commitado no repo como asset estático

### Por que existe

O GitHub deixa você seguir centenas de pessoas mas a página nativa fica inutilizável depois de ~50. É isso que minha lista de seguidores devia ter sido desde o início.
