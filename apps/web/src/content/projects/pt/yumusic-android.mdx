## Sobre o YuMusic Android

Um cliente moderno de streaming de música para Android voltado a bibliotecas auto-hospedadas. Construído com Jetpack Compose e Material 3, projetado com arquitetura limpa em mente (MVVM + Hilt + Room + Coil) para que o código continue testável e modular.

### Stack

- **Jetpack Compose** — UI declarativa
- **Hilt** — injeção de dependências
- **Room** — cache local e playlists
- **Coil** — carregamento rápido de imagens
- **Material 3** — cores dinâmicas do Material You

O app fala a API Subsonic também, então uma única biblioteca cobre o relógio (Garmin), o desktop (Electron) e o Android.
