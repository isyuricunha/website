## Sobre Massage Alternativa

Um projeto de cliente pra uma massoterapeuta baseada no Brasil. O site apresenta o serviço, mostra preços e horários, e torna trivial contactar via WhatsApp ou Instagram.

### Destaques

- Site estático de página única
- HTML/CSS/JS puro, sem framework
- Fonte Sass disponível pra tweaks de tema
- Deep link pro WhatsApp pra agendamento instantâneo
- Embed Google Maps com directions
- Animações leves pra transições de seção
- Google Analytics 4 (gtag) + Umami pra visitor stats

### Trabalho de cliente

Esse é um dos "one-pagers" profissionais que eu já entreguei pra um cliente de verdade. Não é projeto pessoal — mas construído com o mesmo cuidado e velocidade que dou ao meu próprio trabalho.
