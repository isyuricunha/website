## Sobre o Massage Alternativa

Um projeto de cliente para uma massoterapeuta brasileira. O site apresenta o serviço, mostra preços e horários, e torna extremamente fácil entrar em contato pelo WhatsApp ou Instagram.

### Destaques

- Site estático de página única
- HTML/CSS/JS puros, sem framework
- Código Sass disponível para ajustes de tema
- Deep link do WhatsApp para agendamento instantâneo
- Embed do Google Maps com rotas
- Animações leves para transições de seção
- Google Analytics 4 (gtag) + Umami para estatísticas de visitantes

### Trabalho para cliente

Este é um dos one-pagers "profissionais" que entreguei para um cliente real. Não é um projeto pessoal — mas foi construído com o mesmo cuidado e velocidade dos meus próprios projetos.
