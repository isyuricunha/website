## YuCode Theme について

Hermes Agent のデフォルトの出力は騒がしい: 赤/緑の diff ブロックが積み重なった進捗コメントの上に大量に表示されます。**yucode** は Claude Code を参考にしたミニマルなリスキンです — 落ち着いたコーラルアクセント、ニュートラルなグレー、衝突するレインボー diff カラーはなし、デフォルトのマスコットアートの代わりに小さなカスタムバナーを表示します。

### インストーラーが行うこと

- スキンファイルを `~/.hermes/skins/` にコピー
- 表示を **TUI** に切り替え（従来の CLI より格段に読みやすい）
- いくつかの表示設定を変更 — コンパクトモード、新しいツール進捗スタイル
- デフォルトのアートの代わりに yucode バナーを使用

### ファイル

- `yucode.yaml` — スキン
- `install.sh` — ワンショットインストーラー
- `EOF.md` — 貼り付け可能なクイックインストールスニペット

### 要件

`~/.hermes/config.yaml` が存在する、動作中の Hermes Agent のインストール。
