## PokéDex について

1025+ 匹の Pokémon をブラウズするフル機能 PWA。Next.js 15 + TypeScript + Tailwind CSS v4 ベース。どのデバイスにもインストール可能で、オフライン動作、ネイティブライクな操作感。

### 特徴

- **ブラウズ・検索** — リアルタイムフィルタ
- **詳細ステータス** — 基本ステータス、特性、技、進化ツリー
- **タイプ相性** — インタラクティブな相性図
- **チームビルダー** — 最大6匹のチームを組む
- **クイズモード** — シルエット、ステータス、タイプの3種
- **比較** — サイドバイサイドの Pokémon 比較
- **色違い** — シャイニースプライト切替
- **お気に入り＆コレクション** — 図鑑達成度を管理

### なぜ

多くの Pokédex は遅くてメモリリークのある SPA。こちらは PWA として軽量で、画像はローカルキャッシュ、拡張性の高い TypeScript のベース。
