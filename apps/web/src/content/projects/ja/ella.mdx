## Ella について

Ella は GitHub リポジトリ内に常駐し、メンテナーのようにリポジトリの運営を手伝う自律型 AI エージェントです。Issue のトリアージ、PR のレビュー、CI のフォローアップ、人間や他のエージェントとの作業調整を、あなたが普段作業しているのと同じリポジトリの中から行います。

### 主な機能

- GitHub 内にネイティブに常駐 — 外部オーケストレーターは不要
- リポジトリの規約や過去の決定を記憶する長期メモリ
- リポジトリが既に使っているブランチや PR のワークフローに従う
- 周辺のエコシステム（CI、リリース自動化、カンバンボード）と連携
- コードジェネレーターではなく、実際のコラボレーターとして振る舞う

### 動作環境

Ella はこのリポジトリ（[isyuricunha/ella](https://github.com/isyuricunha/ella)）で本番運用されており、このサイトのメンテナーエージェントとして稼働しています。
