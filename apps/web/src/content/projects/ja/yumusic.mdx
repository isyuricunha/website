## YuMusic Desktop について

Garmin 版 YuMusic のデスクトップ版。Navidrome / Gonic / Airsonic など任意の Subsonic 互換サーバーに接続し、セルフホストライブラリを聴くためのクリーンなダークプレイヤー。サードパーティへアップロードされることはありません。

### 特徴

- アーティスト、アルバム、楽曲、プレイリストをブラウズ
- 長時間聴き続けるための落ち着いたダーク UI
- LAN または VPN 越しにストリーミング
- 選択したアルバムをオフラインキャッシュ
- クロスプラットフォーム Electron ビルド (Linux、Windows、macOS)

### なぜ

他の Subsonic クライアントの多くは、余計なごちゃごちゃが多い Web ラッパー。YuMusic はシングルパーパス。音楽を聴くことだけに集中します。
