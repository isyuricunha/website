## Links について

私の SNS を一覧した Linktree 的なミニマルページ。シンプル、高速、完全に静的。

### 特徴

- シングルページ、他は何もなし
- 完全な静的サイト（DB 不要）
- 私のすべての SNS ハンドルがここに
- オープンソース、フォークして使えます

### スタック

- Next.js 15
- Tailwind CSS v4
- pnpm
