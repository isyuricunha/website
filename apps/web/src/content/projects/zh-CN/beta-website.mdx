## 关于 Beta Website

我个人网站的早期版本，使用 **Astro** 重构为更小、更严格的静态站点 —  — 无 React 运行时，无数据库，无 CMS，无服务器函数。内容位于 MDX 中，翻译按语言分成并排文件，并且验证确保每个已发布的英文条目都有其必需的翻译。

### 技术栈

- **Astro**（静态输出，无适配器）
- **Astro 内容集合**，带有严格的前置元数据验证
- **Astro i18n 路由** — 每种语言一个文件夹
- **Tailwind CSS** 用于样式
- **Shiki** 用于代码高亮

### 为何存档

您当前正在阅读的站点（即您现在看到的站点）构建在 Next.js 上，为其提供了适当的服务器运行时，用于评论、webmentions、动态 OG 图像等。Astro 重写是一种更简单的方法，一些项目仍将其作为参考 —  — 它在此保留正是出于此原因，而非因为我仍在发布它。
