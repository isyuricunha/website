## 关于 List All Followers and Following

GitHub 的原生界面使得浏览所有关注者和您关注的人变得痛苦 —  — 没有过滤，没有排序，分页笨拙。此小项目通过将您的完整关注/关注者列表渲染为一个可排序、可过滤的表格来修复这一问题，该表格会根据计划自动更新。

### 关键功能

- 在一个长表中查看**所有**关注者和关注的人（无需点击“加载更多”）
- 按姓名、公司、位置、博客、个人资料实时过滤和排序
- 通过计划的GitHub Action每日自动更新
- 零后端 —  — 数据作为静态资产提交到仓库

### 为什么存在

GitHub 允许您关注数百人，但内置页面在大约50人之后变得不可用。这本应是我的关注列表最初的样子。
