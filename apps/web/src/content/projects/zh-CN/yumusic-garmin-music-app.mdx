## 关于 YuMusic

YuMusic 将您的 Garmin 手表转变为个人 **Subsonic 兼容** 媒体服务器的独立离线音乐播放器 — 支持 Navidrome、Gonic、Airsonic 或 Nextcloud Music。通过 Garmin Connect 手机应用连接后，您可以直接在手表上浏览播放列表，通过 Wi-Fi 下载曲目，并将手机留在家中。

### 关键功能

- **直接服务器同步** — 从您的家庭服务器直接下载播放列表到您的手腕
- **离线播放** — 即使没有互联网连接也能随时随地聆听
- **流畅原生界面** — 快速布局，专注于让您快速找到音乐而无冗余
- **全库随机播放** — 在完整下载库中随机播放
- **离线 scrobble 自动追踪** — 同步回您的服务器
- **音质控制** (320 / 192 / 128 / 96 kbps) — 以适应您的手表存储空间
- **紧凑型多播放列表库** — 共享曲目仅存储一次，而非每个播放列表单独存储
- **安全删除播放列表** — 不会破坏其他播放列表

### 技术栈

基于 Garmin Connect IQ SDK 的 Monkey C 构建，通过 Subsonic API 通信。已针对 Navidrome 和 Gonic 进行测试；与大多数 Subsonic-API 实现兼容。
