## 关于 Ella

Ella 是一个自主的AI代理，设计为居住在您的GitHub仓库中，帮助您像维护者一样运行它们。她可以处理问题（triage），审查拉取请求（PRs），跟进持续集成（CI），并与人类和其他代理协调工作 —  — 所有这些都在您已经在使用的同一个仓库中进行。

### 关键功能

- 本地集成在 GitHub 中 —  — 不需要外部编排器
- 长期记忆存储仓库的惯例和过去的决策
- 遵循仓库已经使用的分支和 PR 工作流程
- 与更广泛的生态系统交互（CI、发布自动化、看板）
- 行动就像一个真正的协作者，而不是代码生成器

### 运行位置

Ella 正在这个非常仓库 ([isyuricunha/ella](https://github.com/isyuricunha/ella)) 上投入生产使用，并担任该站点的维护者代理。
