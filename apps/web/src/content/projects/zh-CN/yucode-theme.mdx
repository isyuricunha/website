## 关于 YuCode Theme

Hermes Agent 的默认输出很吵闹：许多红/绿差异块堆叠在进度注释之上。**yucode** 是一款模仿 Claude Code 风格的极简重皮 —  — 平静的珊瑚色点缀，中性灰色，没有争斗的彩虹差异颜色，以及一个小型自定义横幅，用于替换默认的吉祥物艺术。

### 安装程序的作用

- 将皮肤文件复制到 `~/.hermes/skins/` 
- 将显示切换到 **TUI**（比经典 CLI 更易读）
- 调整几个显示设置 —  — 紧凑模式，新的工具进度样式
- 使用 yucode 横幅替换默认艺术

### 文件

- `yucode.yaml` — 皮肤文件
- `install.sh` — 一键安装脚本
- `EOF.md` — 可粘贴的快速安装片段

### 要求

需要一个正常运行的 Hermes Agent 安装，并且存在 `~/.hermes/config.yaml`。
