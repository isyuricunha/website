## À propos de YuFlow

YuFlow est un gestionnaire de tâches construit autour d'un axiome : **vos données vous appartiennent**. Pas de comptes, pas de cloud, pas de télémétrie, pas d'analytics. L'application tourne entièrement sur votre appareil — en application de bureau Tauri 2.0 ou en PWA web — et stocke tout localement dans SQLite/IndexedDB.

### Manifeste vie privée

- Stockage 100 % local, toujours
- Zéro télémétrie — pas de tracking, pas d'analytics, pas de fingerprinting
- Aucune dépendance au cloud — fonctionne entièrement hors ligne
- Propriété totale des données — exportez, sauvegardez, migrez quand vous voulez
- Code open source auditable

### Fonctionnalités

- Tableaux kanban avec sous-tâches et pièces jointes
- Tâches récurrentes, dates d'échéance, priorités, étiquettes
- Thème sombre « True Pure Black » avec couleurs d'accent
- Versions bureau natives (Tauri) + web (PWA) issues du même code
- Recherche plein texte dans tous les projets

### Stack

TypeScript, Tauri 2 (shell Rust), SQLite sur desktop, IndexedDB dans le navigateur. Aucun composant côté serveur.
