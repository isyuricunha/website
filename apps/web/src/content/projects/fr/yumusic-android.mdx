## À propos de YuMusic Android

Un client de streaming musical Android moderne pour bibliothèques auto-hébergées. Construit avec Jetpack Compose et Material 3, avec une architecture propre en tête (MVVM + Hilt + Room + Coil) pour garder le code testable et modulaire.

### Stack

- **Jetpack Compose** — UI déclarative
- **Hilt** — injection de dépendances
- **Room** — cache local et playlists
- **Coil** — chargement rapide des images
- **Material 3** — couleurs dynamiques Material You

L'application communique aussi avec une API Subsonic, ce qui permet à une seule bibliothèque de couvrir la montre (Garmin), le bureau (Electron) et Android.
