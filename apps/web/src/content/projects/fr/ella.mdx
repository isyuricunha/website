## À propos d'Ella

Ella est un agent IA autonome conçu pour vivre dans vos dépôts GitHub et vous aider à les gérer comme un mainteneur. Elle peut trier les issues, relire les PR, assurer le suivi de la CI et coordonner le travail avec des humains et d'autres agents — le tout depuis le dépôt dans lequel vous travaillez déjà.

### Fonctionnalités clés

- Vit nativement dans GitHub — aucun orchestrateur externe requis
- Mémoire à long terme des conventions du dépôt et des décisions passées
- Suit le workflow de branches et de PR déjà utilisé par le dépôt
- Dialogue avec l'écosystème au sens large (CI, automatisation des releases, tableaux kanban)
- Agit comme un vrai collaborateur, pas comme un générateur de code

### Où elle tourne

Ella est utilisée en production sur ce même dépôt ([isyuricunha/ella](https://github.com/isyuricunha/ella)) et fait office d'agent mainteneur de ce site.
