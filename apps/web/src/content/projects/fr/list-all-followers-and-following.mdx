## À propos de List All Followers and Following

L'interface native de GitHub rend pénible la consultation de l'ensemble de vos abonnés et des personnes que vous suivez — pas de filtrage, pas de tri, une pagination maladroite. Ce petit projet règle le problème en affichant votre liste complète d'abonnements/abonnés sous forme d'un tableau triable et filtrable, mis à jour automatiquement selon un calendrier.

### Fonctionnalités clés

- Voyez **tous** vos abonnés et abonnements dans un seul long tableau (plus de clics « charger plus »)
- Filtre et tri en direct par nom, entreprise, lieu, blog, bio
- Mise à jour quotidienne automatique via une GitHub Action planifiée
- Zéro backend — les données sont commitées dans le dépôt comme un asset statique

### Pourquoi ce projet existe

GitHub permet de suivre des centaines de personnes, mais la page intégrée devient inutilisable au-delà d'une cinquantaine. Voilà à quoi ma liste d'abonnés aurait dû ressembler depuis le début.
