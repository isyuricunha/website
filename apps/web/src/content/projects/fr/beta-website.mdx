## À propos de Beta Website

Une itération antérieure de mon site personnel, reconstruite avec **Astro** comme un site statique plus petit et plus strict — pas de runtime React, pas de base de données, pas de CMS, pas de fonctions serveur. Le contenu vit dans des fichiers MDX, les traductions sont des fichiers côte à côte par locale, et une validation garantit que chaque entrée anglaise publiée possède ses traductions requises.

### Stack

- **Astro** (sortie statique, sans adaptateur)
- **Astro Content Collections** avec validation stricte du frontmatter
- **Routage i18n d'Astro** — un dossier par locale
- **Tailwind CSS** pour les styles
- **Shiki** pour la coloration syntaxique du code

### Pourquoi c'est archivé

Le site actuel (celui que vous lisez en ce moment) est construit avec Next.js, qui lui offre un vrai runtime serveur pour les commentaires, les webmentions, les images OG dynamiques, etc. La réécriture Astro était une approche plus simple que certains projets utilisent encore comme référence — elle survit ici pour cette raison, pas parce que je la maintiens encore.
