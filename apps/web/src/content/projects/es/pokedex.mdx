## Acerca de PokéDex

Una Progressive Web App completa para explorar los más de 1025 Pokémon. Construida con Next.js 15, TypeScript y Tailwind CSS v4: instalable en cualquier dispositivo, funciona sin conexión y se siente nativa.

### Aspectos destacados

- **Explora y busca** todos los Pokémon con filtrado en tiempo real
- **Estadísticas detalladas**: estadísticas base, habilidades, movimientos, cadenas evolutivas
- **Efectividad de tipos**: tabla interactiva de enfrentamientos
- **Armado de equipos**: crea y analiza equipos de hasta 6
- **Modos de quiz**: siluetas, estadísticas y tipos
- **Comparaciones**: análisis de Pokémon lado a lado
- **Variantes shiny**: alterna sprites shiny
- **Favoritos y colecciones**: sigue el progreso de tu propia Pokédex

### ¿Por qué otra Pokédex?

La mayoría son aplicaciones web lentas que desperdician memoria. Esta es una PWA ligera con UI optimista, sprites en caché local y una base de código en TypeScript construida para extenderse.
