## Acerca de Links

Una página minimalista estilo Linktree que enumera todos los lugares donde puedes encontrarme. Simple, rápida, completamente estática, e infinitamente más fácil de compartir que una firma con 7 enlaces.

### Características

- Una sola página, nada más
- Completamente estática (sin API, sin base de datos)
- Una única fuente de verdad para todos los perfiles sociales
- Código abierto, haz fork y adáptalo

### Stack

- Next.js 15
- Tailwind CSS v4
- pnpm

Desplegado en `links.yuricunha.com` y servido desde el CDN edge de Vercel.
