## Acerca de List All Followers and Following

La interfaz nativa de GitHub hace que sea tedioso recorrer todos tus seguidores y las personas que sigues — sin filtros, sin ordenamiento y con una paginación torpe. Este pequeño proyecto lo resuelve mostrando tu lista completa de seguidos/seguidores como una tabla ordenable y filtrable que se actualiza automáticamente según un calendario.

### Características principales

- Ve **todos** los seguidores y seguidos en una sola tabla larga (sin clics en "cargar más")
- Filtrado y ordenamiento en vivo por nombre, empresa, ubicación, blog, biografía
- Actualización diaria automática mediante un GitHub Action programado
- Sin backend — los datos se guardan en el repositorio como un recurso estático

### Por qué existe

GitHub te permite seguir a cientos de personas, pero su página integrada se vuelve inutilizable pasadas unas 50. Esto es lo que mi lista de seguidores debería haber sido desde el principio.
