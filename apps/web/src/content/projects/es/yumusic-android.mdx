## Acerca de YuMusic Android

Un cliente moderno de streaming de música para Android orientado a bibliotecas autoalojadas. Construido con Jetpack Compose y Material 3, diseñado con arquitectura limpia en mente (MVVM + Hilt + Room + Coil) para que la base de código siga siendo testeable y modular.

### Stack

- **Jetpack Compose**: UI declarativa
- **Hilt**: inyección de dependencias
- **Room**: caché local y playlists
- **Coil**: carga rápida de imágenes
- **Material 3**: colores dinámicos de Material You

La app también se comunica con una API Subsonic, así que una sola biblioteca cubre el reloj (Garmin), el escritorio (Electron) y Android.
