## Acerca de Massage Alternativa

Un proyecto para un cliente: una masajista con sede en Brasil. El sitio presenta el servicio, muestra precios y horarios, y hace que contactar por WhatsApp o Instagram sea sumamente fácil.

### Aspectos destacados

- Sitio estático de una sola página
- HTML/CSS/JS puro, sin frameworks
- Código Sass disponible para ajustes de tema
- Enlace directo a WhatsApp para agendar al instante
- Mapa de Google Maps integrado con indicaciones
- Animaciones ligeras para las transiciones entre secciones
- Google Analytics 4 (gtag) + Umami para estadísticas de visitas

### Trabajo para cliente

Este es uno de los one-pagers "profesionales" que he entregado para un cliente real. No es un proyecto personal, pero fue construido con el mismo cuidado y rapidez que mi propio trabajo.
