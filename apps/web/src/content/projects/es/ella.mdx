## Acerca de Ella

Ella es una agente de IA autónoma diseñada para vivir dentro de tus repositorios de GitHub y ayudarte a gestionarlos como un mantenedor. Puede clasificar issues, revisar PRs, dar seguimiento al CI y coordinar el trabajo con humanos y otros agentes — todo desde dentro del mismo repositorio en el que ya trabajas.

### Características principales

- Vive de forma nativa dentro de GitHub — no requiere un orquestador externo
- Memoria a largo plazo de las convenciones del repositorio y decisiones pasadas
- Sigue el flujo de ramas y PRs que el repositorio ya utiliza
- Se comunica con el ecosistema más amplio (CI, automatización de releases, tableros kanban)
- Actúa como una colaboradora real, no como un generador de código

### Dónde se ejecuta

Ella se usa en producción en este mismo repositorio ([isyuricunha/ella](https://github.com/isyuricunha/ella)) y actúa como la agente mantenedora de este sitio.
